CampusFit – Fitness and Health Management System


Project Overview

CampusFit is a Fitness and Health Management System developed to help students maintain a healthy lifestyle while managing academic responsibilities. The application provides tools for workout planning, nutrition tracking, health monitoring, and feedback management within a single platform.

The system focuses on personalized fitness recommendations by considering user fitness profiles and academic schedules, enabling students to balance their studies and health effectively.

Objectives

Provide a centralized platform for fitness and health management.
Help users create and maintain personalized workout plans.
Monitor nutritional intake and calorie consumption.
Track health-related information and fitness consistency.
Generate useful health insights and recommendations.
Collect user feedback to improve the application.
User Roles
Guest User

A guest user can access the application and register for a new account or log in to an existing account.

Registered User

A registered user has access to all application features, including workout planning, nutrition tracking, health monitoring, and feedback submission.

Administrator

The administrator reviews user feedback and manages application improvements based on user suggestions and ratings.
